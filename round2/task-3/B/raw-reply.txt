**I have successfully added the new statue guard enemy to the game.** Here's a summary of the changes:

## New Enemy: Statue Guard

The statue guard is a stationary enemy that:
- Waits for Vel to approach (within ~200 pixels)
- Raises its spear and pauses for exactly 1 second
- Throws a spear in a straight line that can be jumped over
- Takes exactly 2 arrow hits to destroy
- Matches the game's pixel art style and color palette

## Gameplay Integration

The guards are fully integrated with existing game systems:
- **Arrow hits**: Reduce HP, flash effect, 2 hits needed for destruction
- **Player detection**: Only become active when player is within range
- **Art style**: Uses the same pixel art techniques as other enemies

The new enemy provides a challenging encounter that tests timing (jumping over spears) while fitting seamlessly into the existing game world and visual style.
